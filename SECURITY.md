# Сообщение об уязвимости

Не публикуйте открытый issue для уязвимостей, связанных с OAuth, токенами, авторизацией или API. Напишите сопровождающим проекта приватным каналом GitHub Security Advisories. Укажите затронутую версию, влияние и безопасные шаги воспроизведения. Не включайте действующие секреты в отчет.
