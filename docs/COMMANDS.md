# Команды

Каждая команда находится в отдельном файле в `src/commands/`. Бот регистрирует её `name` и `aliases`. Команда погоды загружается только при `ENABLE_WEATHER=true`.

```js
export default {
  name: 'ping',
  aliases: ['пинг'],
  cooldown: 5,
  async execute({ client, channel, user, args, message }) {
    client.say(channel, `@${user}, pong!`);
  },
};
```

`cooldown` указывается в секундах и действует отдельно для команды и пользователя. `execute` получает client, канал, логин, массив аргументов и разобранное сообщение. Неизвестные команды игнорируются. Ошибки команды логируются, не останавливая бота.

Модераторы могут добавлять команды через `!newcmd` / `!addcom` / `!дк` / `!lr` / `!эдком`, менять через `!editcmd`, удалять через `!delcmd` / `!del` / `!delcom` / `!делит`, а также переключать через `!oncmd` и `!offcmd`.

## Встроенные команды

- `!пинг` / `!ping` — ответ `pong`.
- `!аптайм` / `!uptime` — время работы процесса.
- `!команды` / `!help` / `!commands` — краткая справка.
- `!погода <город>` / `!weather <city>` — погода, если `ENABLE_WEATHER=true`.
- `!title` / `!тайтл` / `!название` — показать название; с текстом у модератора меняет его.
- `!game` / `!игра` / `!category` / `!категория` — показать категорию; с названием у модератора меняет её.
- `!elo` / `!эло` / `!удщ` — FACEIT Elo игрока по умолчанию; `!elo <ник>` запрашивает другого игрока.
- `!setuser <ник>` — установить игрока FACEIT по умолчанию; доступно модераторам.
- `!рандомчат [1-5]` — случайные активные участники; только модератор или владелец.
- `!so <ник Twitch>` — shoutout; нужен scope `moderator:manage:shoutouts`.
- `!клип` / `!clip` — создать клип текущего эфира; нужен scope `clips:edit`.
- `!проги` — показать сохранённые пресеты локальных прогнозов.
- `!прог` — показать активный прогноз и оставшееся время.
- `!закрытьпрог` / `!отменапрог` — завершить прогноз с результатом или отменить его; только модератор или владелец.

## Управление стримом

Эти команды принимает бот от модератора или владельца канала. Twitch также проверяет права токена бота.

| Команда | Действие | Scope токена |
|---|---|---|
| `!сменназвание <текст>` / `!settitle` / `!title <текст>` | Сменить название, до 140 символов | `channel:manage:broadcast`, токен владельца |
| `!сменкатегорию <точное название>` / `!setcategory` / `!game <категория>` | Сменить категорию Twitch | `channel:manage:broadcast`, токен владельца |
| `!слоу <3–120 секунд\|выкл>` / `!slow` | Slow mode | `moderator:manage:chat_settings` |
| `!фолловеры <0–129600 минут\|выкл>` / `!followers` | Followers-only | `moderator:manage:chat_settings` |
| `!эмоуты <вкл\|выкл>` / `!emotes` | Emote-only | `moderator:manage:chat_settings` |
| `!очиститьчат` / `!clearchat` | Очистить чат | `moderator:manage:chat_messages` |

Погода использует Open-Meteo без API ключа. Пустой `WEATHER_ALLOWED_USERNAMES` оставляет ее доступной всем; заполненный список ограничивает команду указанными логинами.

Свои команды, включая `!инфоком`, `!копком`, `!экспортком` и `!импортком`, а также таймеры, автоответы, напоминания, закрепы, опросы и локальные прогнозы описаны в [функциях чата](CHAT_FEATURES.md).
